# Repository Rules

- This repository contains a standalone React/Vite teaching tool for first-order low-pass filters.
- Keep all runtime behavior client-side; do not add a backend or external data service.
- `package.json.version` is the displayed application version and release source of truth.
- Run `npm run lint`, `npm test`, and `npm run build` before committing.
- Do not commit `dist`, source maps, credentials, or local environment files.
- GitHub Pages releases are created only from semantic-version tags.
