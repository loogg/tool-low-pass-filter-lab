## 方案与已知审核项

```text
导航 / 共享参数 -> App
                     +-> 连续原型 / 概念
                     +-> 数字仿真（独立参数，可载入共享值）
                     +-> 约束选型 -> 应用 fc
                     +-> C 代码（与递推及初始化约定一致）
所有计算 -> lib/filterMath.js -> 单元测试 / 来源审核
图表     -> 按需加载 ECharts -> 真实浏览器审查
```

实施前已识别：极点匹配与严格 ZOH 的输入索引差异；数字实际 −3.0103 dB 点；离散响应按整数更新次数判定；超预算分块近似改变波形；抽点/连续曲线产生显示混叠；生成代码与仿真初始化不一致；输入编辑/剪贴板失败反馈。

## 交付与覆盖边界

实现、模型依据、九章设计原则对应、源码和上述验证结果均已保存。本地预览继续运行，版本仍为 0.1.11。
