# 专业分析工作台

依据：用户要求去除宣传式大标题、采用工程坐标，并已确认“打开即分析、物理单位默认、参数变化可比较、结果可核验”的修订方案。色彩与细线风格继续参考 Cap，交互结构按工程任务组织。

## 入口与状态

- 默认入口为 `#response`；旧 `#concept` 与未知 hash 规范化为 `#response`。
- 导航为分析、仿真、指标选型、代码、理论。主标题统一 20px，删除 Hero、口号与探索 CTA。
- 共享 fc、fs、方法仍由 App 管理。τ 输入反向换算 fc，二者不保存成两份独立状态。无修改的输入离焦不重新提交舍入后的显示值。
- 仿真保留既有独立设置，并明确标注；通过“载入分析滤波参数”显式同步，避免隐藏覆盖实验设置。
- 图表显示模式、时间窗、纵轴、游标由分析组件管理。切换工作区保留已访问页面的本地状态。

## 坐标与时间窗

- 阶跃默认真实时间轴，按窗口量级选择 s / ms / μs / ns / ps，轴名称明确单位，刻度统一用该单位。
- 自动窗口约为 5τ，再按 1/2/5 刻度体系向上取易读边界；fc=2.5Hz 时为 0–320ms、主刻度 50ms。
- 固定模式先锁定当前物理时长；修改 fc 只改变响应，不改变时间窗。时间窗输入支持工程单位和科学计数法，提交后进入固定模式。
- 归一化模式用 t/τ（无量纲），只转换同一物理时长的数据坐标；不作为默认工程读数。
- 阶跃纵轴可选无量纲幅值与百分比；坐标、浮动读数和图下读数遵循同一比例。
- 频域横轴采用 Hz 的对数频率表达，增益轴 dB、相位轴 °。数字或对比模式绘至 fs/2，不把越界频率伪装成独立数字频率。

## 模型与读数

- 连续原型使用解析式 `−expm1(−t/τ)`；在快速变化段分配足够绘图点，保留 τ、t95、t99 和窗口末点。
- 当前输入数字 EMA 使用解析阶跃 `y[n] = 1 − (1−α)^(n+1)`，初始状态 y[−1]=0，绘图横坐标严格为 nTs。少量样本以采样点及阶梯线呈现；大量样本只抽取真实采样时刻，不冒充逐点循环仿真。
- 连续/数字对比使用灰色虚线与蓝色采样曲线。连续标记为 τ、t95、t99；仅数字模式标记离散首达采样时刻。
- 游标在实际坐标位置计算连续值。数字读数取最近的有效采样点，并同时注明 n 和 t[n]，不将其误当作任意时刻的连续值。
- 模型特征表分列连续/数字的时间常数、95%/99% 首达时间和半功率截止。数字首达时刻 `(N−1)Ts` 与更新预算 `NTs` 同时说明。

```text
fc / τ <-> App 共享参数 -> 响应计算（responseAnalysis + filterMath）
                              |-> H(s) 连续曲线
                              |-> H(z) 采样点
时间窗 / 坐标模式 ------------>|-> 单位变换 -> ECharts
ECharts 游标事件 -> 实际坐标解析 -> 图下读数
```

数学依据沿用 [模型审核](model-audit.md)。真实时间单位与可配置时间范围参考 [MathWorks stepplot](https://www.mathworks.com/help/control/ref/stepplot.html)。实施与检查结果统一记录在 [当前验收文档](../acceptance/2026-10-27-refactor.md)。
