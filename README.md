# LPF·LAB：一阶低通滤波交互实验室

一个面向初学者和嵌入式开发者的纯前端教学工具。它把一阶低通滤波器的三个常见参数——时间常数 `τ`、截止频率 `fc`、数字系数 `α`——放进同一套可交互实验中，帮助用户从公式建立到工程选型，再落到 MCU 代码。

## 主要功能

- 五个一级教学工作区改为桌面端左侧竖向导航：`直觉 / 响应 / 模拟 / 选型 / 代码` 点击切换，不再把所有章节堆成一张超长页面；手机端自动转为横向可滑动导航。
- 全局 `fc` 与 `fs` 独立设置：`fc` 支持 `1 mHz ～ 50 MHz`，`fs` 支持 `1 Hz ～ 200 MHz`，数值输入可切换 `Hz / kHz / MHz`。
- 响应与代码工作区采用固定的“左侧纵向参数、右侧分析结果”布局；响应页明确只展示连续原型，数字幅相集中在模拟页，避免把两套结果混在一起。
- 普通计算结果区同时列出数字实现、时域响应、幅相响应和实时计算负载，并用具体差值示例解释 `α` 的含义。
- 直觉工作区的采样边界区给出 `fN = fs/2`、混叠通用公式与四个 Nyquist 区的正向/镜像折尺。
- 阶跃响应横轴以 `1τ ～ 5τ` 标注，配合幅频响应和相频响应原生 SVG 图表建立直觉。
- 幅频图直接标注 `−3 dB ≈ 0.707×`、`−20 dB ≈ 1/10`、`−40 dB ≈ 1/100`，并区分幅值比与功率比公式。
- 仿真器采用紧凑的统一双栏工作台，不再设置二级 Tab，也不重复显示工作区工具栏与大标题：桌面端打开模拟页即进入左侧全部参数、右侧 LIVE 信号分析与结果，两栏可独立滚动。
- 模拟信号、滤波器与 ADC、噪声干扰、观察窗口和计算预算按信号链分组；手机端自动改为“全部参数在前、全部图表在后”的单列结构。
- 仿真器拥有独立的 `fc`、`fs` 与离散方法，也可一键载入全局参数后继续单独调整。
- 正弦、方波、阶跃三类输入全部开放工程参数：频率、幅值、偏置、相位、占空比、阶跃电平与时刻、噪声种子、周期干扰、递推初值和观察窗口等。
- 主信号与周期干扰频率支持 `1 mHz ～ 2fs`，可以跨越 4 个 Nyquist 区，并提供 `0.6fs / 0.9fs / 1.1fs / 1.6fs` 一键折回示例。
- 仿真分析图按需加载专业 ECharts Canvas：支持十字光标、滚轮/框选缩放、恢复视图、图片导出，以及点击图例逐条显示或隐藏曲线。
- LIVE 图把采样前模拟信号、ADC 样本、折回等效参考和数字低通输出放在同一坐标系；橙色原始曲线强化显示，超过 `fN` 时可直接比较原频率与 `f_alias`。
- Nyquist 折回计算已嵌入 LIVE 图上方，以“寻找离 `fin` 最近的 `fs` 整数倍”为主要心算法，并把 `mod + min` 收进可展开的程序等价公式；另提供 `0.6fs / 0.9fs / 1.1fs / 1.6fs` 一键例题。
- 幅频与相频合并为一张深色双轴图，共用对数频率轴，并同时标出 `fc`、`f_alias` 及当前测量点。
- 仿真结果区分 ADC 前模拟原型在原始频率处的响应，以及 ADC 后数字滤波器在混叠频率处的实际响应。
- 仿真结果还输出 dB、数字相位、数字群时延、离散等效时间常数、真实采样点数、递推步数、绘图点数、RMS 与实时运算速率。
- MHz 级采样采用明确标注的等效分块递推，真实参数和计算负载仍按设置的 `fs` 计算，避免浏览器因数亿次循环冻结。
- ZOH 精确离散与后向欧拉系数对比。
- 时域、通带、阻带三类设计约束直接按当前 ZOH / 后向欧拉数字传递函数求交，并严格校验目标频率低于 Nyquist 边界。
- 自动生成可复制的嵌入式 C 实现；极小 α 会使用科学计数法，避免宽频率范围下被舍入为零。
- 响应式布局、键盘可操作控件和减少动态效果支持。

## 核心关系

```text
τ = 1 / (2πfc)

y[n] = y[n-1] + α(x[n] - y[n-1])

ZOH:             α = 1 - exp(-2πfc / fs)
Backward Euler:  α = 2πfc / (fs + 2πfc)

fN = fs / 2
k = round(fin / fs)
falias = abs(fin - k * fs)

# 程序等价写法
r = fin mod fs
falias = min(r, fs - r)
```

## 设计原则

- 先给直觉，再给公式。
- 每个数字都配即时工程解释。
- 不把 `fc` 描述成硬边界。
- 不把 `fs/2` 描述成“超过后消失”：明确展示相邻 Nyquist 区会交替镜像折回。
- 不把 `fN` 本身说成完整无歧义频带：完整幅相要求 `0 ≤ f < fN`，边界单独提示退化。
- 不把后向欧拉误称为 Tustin。
- 明确一阶滤波器、抗混叠和离群值处理的能力边界。
